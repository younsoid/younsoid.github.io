                              NGS Report 정제 - CNV Type 수정, 중복 샘플 제거 #

                              #2026-07-06

                              1. 작업 개요 #

                              기존 작업에서 326명의 NGS Report 추출 결과를 바탕으로 CNV, Fusion, MSI, TMB 데이터를 추출해줬다. 이번 작업에서는 중복인 샘플에 대해서 SNV 추출시 Report를 사용했던 데이터만 남기도록 중복 샘플을 제거해주고, CNV Type이 4분류였던걸 Gain Loss 2분류로 바꿔주려고 한다.

                              #

                              2. 작업 내용 #

                              cnv_data = pd.read_csv("/Users/yshmbid/Documents/home/github/kosmos/workspace/data/0703/368명_대상자_CNV.csv")
fusion_data = pd.read_csv("/Users/yshmbid/Documents/home/github/kosmos/workspace/data/0703/368명_대상자_Fusion.csv")
msi_data = pd.read_csv("/Users/yshmbid/Documents/home/github/kosmos/workspace/data/0703/368명_대상자_MSI_TMB.csv")
tmb_data = pd.read_csv("/Users/yshmbid/Documents/home/github/kosmos/workspace/data/0703/368명_대상자_TMB.csv")

print(cnv_data['COYP_NO_ATRT_TYPE'].value_counts(dropna=False))
cnv_data

                              먼저 CNV 데이터의 Copy Number Type을 확인해보면 위와 같다.

                              cnv_data['COYP_NO_ATRT_TYPE'] = cnv_data['COYP_NO_ATRT_TYPE'].replace({
    'Amplification': 'Gain',
    'Deletion': 'Loss'
})

print(cnv_data['COYP_NO_ATRT_TYPE'].value_counts(dropna=False))
cnv_data

                              Amplification은 Gain, Deletion은 Loss로 바꿔준 결과 Gain 703개, Loss 494개가 되었다.

                              다음 작업으로 중복 샘플을 확인하고 제거하는 작업을 진행해준다.

                              vc = tmb_data['SUBJ_ID'].value_counts(dropna=False)
vc[vc >= 2]

# SUBJ_ID
# S027-012    2
# S009-008    2
# S014-002    2
# S009-007    2
# S006-124    2
# S003-078    2
# S007-026    2
# S003-904    2
# S014-011    2
# Name: count, dtype: int64

                              TMB 데이터를 기반으로 중복 샘플을 확인하였고 9개 샘플이 중복인것을 확인했다.

                              dup_ids = msi_data['SUBJ_ID'].value_counts()
dup_ids = dup_ids[dup_ids >= 2].index
msi_data[msi_data['SUBJ_ID'].isin(dup_ids)].sort_values('SUBJ_ID')

                              중복 샘플의 MSI와 TMB 데이터는 위와 같았다. 중복 중 삭제해줄 Index는 다음과 같고

                              • S003-078: 247 (248만 Tissue 검체)
                              • S003-904: 223
                              • S006-124: 168 (Panel이 등록되어 있지 않음)
                              • S007-026: 163
                              • S009-007: 150
                              • S009-008: 148
                              • S014-002: 84
                              • S014-011: 76 (76이 첫번째, 77이 두번째 수령)
                              • S027-012: 25

                              아래와 같이 해당 Index들을 제거해줬다

                              print(msi_data.shape, tmb_data.shape) # (338, 5) (338, 3)

drop_indices = [247, 223, 168, 163, 150, 148, 84, 76, 25]
msi_data = msi_data.drop(index=drop_indices)
tmb_data = tmb_data.drop(index=drop_indices)

print(msi_data.shape, tmb_data.shape) # (329, 5) (329, 3)

                              중복 제거 결과 MSI, TMB 데이터 수는 338개에서 (샘플 수와 동일한) 329개가 되었다.

                              비고로, S006-124은 MAF가 존재하지 않아서 SNV 분석이 진행되지 않아서 Panel로 선택해줬다. S014-011는 SNV 분석에 두 Report 모두가 사용되어서 (생각해보니 SNV 단위의 중복제거만 수행하고 Report가 2개 이상인 경우 선택하는 과정은 없었음) 두번째로 수령한 Report가 맞다고 가정하고 해당 Report의 데이터를 남겼다.

                              cnv_data[cnv_data['SUBJ_ID'].isin(dup_ids)].sort_values('SUBJ_ID').head(20)

                              다음으로, 중복 샘플의 CNV 데이터는 위와 같았다. 중복 샘플 9건 중에는 S003-078처럼 중복 CNV가 없는 경우도 있고, S003-904처럼 같은 값으로 중복되는 경우도 있었다. 동일 유전자이면서 Type이 다른 값으로 중복되는 CNV는 없었다. 그래서 (원래 하려던 방법인) SNV에 사용한 NGS Report를 찾은 다음에 그 Report의 Type을 따르도록 할 필요가 없고 중복인 경우를 제거하는 방식으로 작업해도 같은 결과여서 그렇게 작업해줬다.

                              print(cnv_data.shape) # (1254, 3)
cnv_data = cnv_data.drop_duplicates(subset=['SUBJ_ID', 'GENE_CMNT', 'COYP_NO_ATRT_TYPE'])
print(cnv_data.shape) # (1238, 3)

                              작업 결과 16개 CNV가 제거되어서 1,238개 데이터가 되었다.

                              마지막으로 Fusion 데이터에서 중복 샘플에 해당하는 데이터는 아래 1개였고

                              확인해보니 중복 중 삭제 예정인 Report에서 추출한 Fusion 데이터여서 해당 항목도 삭제해줬다.

                              print(fusion_data.shape) # (112, 7)
fusion_data = fusion_data[~fusion_data['sample_id'].isin(dup_ids)]
print(fusion_data.shape) # (111, 7)

                              작업 결과 1개 Fusion이 삭제되어서 111개 데이터가 되었다.

                              cnv_data.to_csv("/Users/yshmbid/Documents/home/github/kosmos/workspace/data/0703/368명_대상자_CNV_revised.csv", index=False)
fusion_data.to_csv("/Users/yshmbid/Documents/home/github/kosmos/workspace/data/0703/368명_대상자_Fusion_revised.csv", index=False)
msi_data.to_csv("/Users/yshmbid/Documents/home/github/kosmos/workspace/data/0703/368명_대상자_MSI_TMB_revised.csv", index=False)
tmb_data.to_csv("/Users/yshmbid/Documents/home/github/kosmos/workspace/data/0703/368명_대상자_TMB_revised.csv", index=False)

                              최종적으로 Duplicate가 제거된 CNV, Fusion, MSI, TMB 데이터를 ‘_revised’로 저장해줬다.
