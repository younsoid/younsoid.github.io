                    #2026-10-14

                    1. 외부 검증 코호트 CPTAC

                    CPTAC 폐암은 두 개의 독립 연구로 구성된다.

                    LUAD는 Gillette 등(2020, Cell)이 종양 110개와 짝지어진 정상 인접 조직 101개를 유전체, 후성유전체, 심층 단백체, 인산화·아세틸화 단백체로 종합 분석했다.

                    LSCC는 Satpathy 등(2021, Cell)이 분석했으며 그 데이터 유형에 DNA 메틸화(DNAme)와 인산화·아세틸화·유비퀴틴화 단백체가 포함돼있다. H&E 슬라이드는 TCIA에서 받는다.

                    다른 연구들이 CPTAC를 쓸 때 보고한 내용을 보면, Dolezal 등은 CPTAC에서 416명(LUAD 203, LUSC 213)의 슬라이드 1,306장을 사용했고, CPTAC-LSCC에는 별도의 진단 열이 없어 모든 슬라이드를 편평세포암으로 지정했다.

                    즉 CPTAC는 환자당 슬라이드가 여러 장(평균 3장 이상)이고 정상 조직 슬라이드도 섞여 있으므로, TCGA와 같은 “환자당 1개” 규칙을 어떻게 적용할지(종양 슬라이드만, 첫 번째 또는 전체 평균) 미리 정해야 한다.

                    Murchan 등은 TCGA-LUAD와 CPTAC-LUAD 코호트의 임상병리 특성 차이를 Fisher 정확 검정, 카이제곱 검정, Mann–Whitney U 검정으로 비교했는데 이것이 TRIPOD+AI가 요구하는 “개발-평가 데이터 분포 비교"에 해당하는 전형적 방식이다.

                    Tomita 등은 CPTAC-3 LUAD의 111예를 외부 검증에 사용했고, EGFR 변이 예측 AUROC가 내부 0.799에서 CPTAC-3 0.686으로 낮아졌다. (외부 검증에서 이 정도 하락은 흔하므로 미리 기대치를 잡아 두는 게 좋다)

                    CPTAC를 쓸거면 세가지를 확인해야한다.

                    첫번째는 라벨 재현 가능성인데 Thorsson의 LF·SF 등은 TCGA에만 계산되어 있으므로, CPTAC에서는 같은 방법으로 메틸화에서 LF를 다시 계산하거나, 이 연구의 라벨 (f) 디컨볼루션처럼 직접 계산 가능한 라벨로만 외부 검증해야 한다.

                    두번째는 메틸화 플랫폼 차이다. CPTAC 메틸화가 450K가 아닌 EPIC 배열이라면, 라벨 (d)(e)에 쓴 probe가 EPIC에 있는지 교집합을 확인하고 그 수를 보고해야 한다(플랫폼은 데이터 포털에서 직접 확인).

                    세번째는 파운데이션 모델 사전학습 데이터 중복이다. EXAONEPath 1.0·2.5의 사전학습에 CPTAC가 들어갔다면 외부 검증의 독립성이 깨지므로, 14 노트북에서 TCGA 포함 여부를 확인할 때 CPTAC도 함께 확인해 적어둬야 한다.
