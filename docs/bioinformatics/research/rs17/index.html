                    폐암 데이터 확인 (01~04) #

                    #2026-10-27

                    TCGA 폐암 데이터를 확인하는 01~04번 파일을 돌려봤다.

                    01_inventory #

                            slides  svs_ok  embedded
cancer                          
LUAD       404     404       403
LUSC       347     347       347

                    LUAD는 이미지 404장, LUSC는 347장이다.

                    이미지 전처리를 (나름) 해서 exaonepath 1.0으로 임베딩해줬었는데 유효한 타일이 하나도 없는 파일이 하나 있어서 (TCGA-44-7661-01Z-00-DX1) 1장 빼고 750장이 임베딩됐다.

                    02_cohort #

                            slides  included  tss  no_fold
cancer
LUAD       404       403   33        0
LUSC       347       347   34        0

                    임베딩해놓은 750개는 LUAD 33개 기관, LUSC 34개 기관의 데이터이다.

                    fold는 모델 input에 사용하려고 분리한 배치인데 모든 데이터가 분할 데이터에 잘 들어가있고

                    분배를 보면 한 기관은 하나의 fold에 모두 속해있다. 기관에 따른 변동성은 잡음인데 이렇게 넣었을때도 성능이 좋으면 기관 잡음에 강건한 모델이라는게 된다.

                    WSI에 붙어있는 다른 오믹스 데이터인데 DX, RNA, 메틸화(Meth450)는 모두 있는 샘플만 골랐고 CNV, MAF, miRNA는 일부가 없다. RPPA는 단백질 데이터인데 이게 제일 loss가 많다.
