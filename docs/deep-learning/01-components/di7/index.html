                            확률적 경사 하강법 #

                            #2026-07-31

                            미분가능한 함수의 최솟값은 도함수가 0인 지점으로 구할수있다. 0인 지점을 모두 찾아서 그중 함수값이 가장 작은 포인트를 찾으면 된다.

                            신경망에서는 가장 작은 손실함수의 값을 만드는 가중치 조합을 찾으려면, grad(f(W), W) = 0을 풀면 된다. 식은 모델의 가중치 개수만큼의 변수로 이루어진 다항식이다.

                            근데 실제 신경망에서는 파라미터 개수가 수천개보다 적은 경우가 거의 없고 수천만개일때도 있어서 해석적으로 해결하기는 어렵다. 대신에 파라미터 배치별로 그래디언트를 계산해서 그래디언트의 반대방향으로 파라미터 배치를 이동시키는 방법을 쓰면 구현 가능하다.

                            먼저 훈련샘플 배치 x와 타깃 y_true가 있을때 x로 모델을 돌려서 y_pred를 구한다. (정방향 패스) 그리고 손실을 계산한다. 그리고 모델의 파라미터에 대한 손실 함수의 그래디언트를 계산한다. (역방향 패스 backward pass)

                            그리고 그래디언트의 반대방향으로 파라미터를 조금 이동시킨다. 예를 들어 W -= learning_rate*gradient를 하면 배치에 대한 손실이 감소할 것이다. 이것이 미니 배치 확률적 경사 하강법(SGD)이다.

                            반복마다, 즉 배치마다 하나의 샘플과 하나의 타깃을 뽑으면 true SGD가 된다. 반대로 모든 가용 데이터를 배치마다 뽑으면 배치 SGD가 된다. 더 정확하게 업데이트되지만 비용이 크다. 두 극단을 효율적으로 절충해서 적절한 크기의 미니 배치를 사용해야 할것이다.

                            또, 업데이트할 다음 가중치를 계산할때 현재 그래디언트값만 보지 않고 이전에 업데이트된 가중치를 여러 다른 시각으로 고려할수있다. 예를 들어 모멘텀을 사용한 SGD, Adagrad, RMSProp 등이다. 이런 추가 방법들을 옵티마이저라고 한다.

                            모멘텀은 SGD의 문제점인 수렴 속도와 지역 최솟값을 해결한다.

                            물리학에서 모멘텀은 현재 기울기값과 현재 속도를 고려해서, 즉 현재 가속도와 과거 가속도의 영향을 모두 고려해서 값을 조절한다. SGD에 적용된 모멘텀은 현재 그레디언트 값과 이전 파라미터 업데이트를 고려해서 파라미터 w를 업데이트하는 방식으로 지역 최솟값을 해결한다.
