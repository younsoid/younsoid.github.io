                              매니폴드 가설과 보간 #

                              #2026-08-11

                              1. 매니폴드 #

                              MNIST 숫자 이미지는 28x28 픽셀이고 0부터 255까지 총 256가지 밝기를 가질수있다. 총 256x784개 데이터 포인트가 “숫자 이미지” 데이터 공간에 존재한다.

                              여기서 “실제(유효한) 숫자” 이미지들은 공간의 매우 일부를 차지한다.

                              “숫자 이미지” 데이터 공간에서 유효한 “3” 이미지들은 다른 유효한 “3” 이미지와 붙어있을 것이다. 즉 연속적이다.

                              3은 유효한 다른 숫자 이미지와도 연속성을 보인다. 3과 6을 고른다고 하면, 3에서 6으로 가는 부드러운 길이 존재하고, 그 길 위에 3과 6 사이의 애매한 숫자가 나온다.

                              즉 “유효한 숫자” 이미지들은 연속적이다. 이렇게 저차원이고 연속적이며 국부적으로 평평해보이는 구조를 매니폴드라고 한다. 기술적으로는 손글씨 숫자가 가능한 모든 28x28 unit8배열로 이루어진 공간 안에서 매니폴드를 형성한다고 한다.

                              국부적으로는 평평하다는 말은 무슨 뜻일까?

                              매니폴드는 국부적으로는 선형(유클리드) 공간과 비슷하게 보이는 부모 공간의 저차원 부분 공간이다. 예를 들어 평면상의 매끄러운 곡선은 2D 공간 안에 있는 1D 매니폴드이다. 이 곡선의 모든 포인트에서 접선을 그릴수 있기 때문이다. 3D 공간의 매끄러운 표면은 2D 매니폴드이다.

                              #

                              2. 보간 #

                              매니폴드 가설은 모든 데이터가 겉보기엔 고차원 공간에 인코딩되어 있지만 실제로는 저차원 매니폴드 위에 놓여 있다는 가설이다. 즉 우주에 담긴 정보가 항상 어떤 구조를 갖고 있다는 것이다.

                              이 가설로써 모델의 학습 대상이 256x784개 데이터 전체가 아니라 얇고 저차원인 표면으로 줄어들게 된다.

                              그리고 매니폴드 위 유효한 데이터 2개가 있으면 이를 잇는 연속적인 길 위의 모든 점도 유효한 데이터로 볼수있다. 이렇게 길 위의 유효한 데이터를 찾는 것을 보간이라고 한다.

                              데이터 포인트를 보간할수있으면, 모델이 새로운 포인트를 매니폴드에서 가까운 다른 포인트와 연결해서 이해할 수 있다. 즉 공간 안의 샘플만 사용해서 공간 전체를 이해할 수 있다. 보간을 사용해서 빈 곳을 채울수있기 때문이다.

                              이를 지역 일반화라고 한다.

                              사람의 인지 메커니즘은 보간과 달리 인접한 데이터 포인트의 정보가 없는 상황에도 대응한다. 이를 궁극 일반화라고 한다.

                              인지 메커니즘은 추상화, 세상에 대한 상징적 모델, 추론, 논리, 상식, 일반적으로 이성이라고 부르는 세상에 대한 선천적 능력을 말하며, 이는 직관이나 패턴 인식과는 다르다. 즉 추론이나 논리는 보간만으로 불가능하다.

                              #

                              3. 딥러닝 #

                              실제 데이터는 2D 종이를 구겨놓은 3D 종이공이다. 즉 3차원이지만 본질은 2차원 매니폴드인 것이다.

                              딥러닝은 고차원 공간에서 잠재 매니폴드를 펼치는 도구이다.

                              딥러닝 모델은 근본적으로 고차원 곡선이다. (함수) 이 곡선은 매끄럽고 연속적이어야한다. 경사 하강법으로 학습하려면 미분 가능해야하기 때문이다. 그리고 모델 구조가 주는 가정(prior)를 따르는 규칙적인 곡선이다.

                              딥러닝의 학습은 무작위 초기 상태에 곡선이 아무렇게나 놓여있으면, 경사 하강법으로 이 곡선을 훈련 데이터 점에 맞추는 과정이다. 즉 크고 복잡한 곡선을 하나 고르고, 파라미터를 조정하면서 훈련 데이터에 맞을때까지 다듬는 과정이다.

                              앞서 실제 데이터는 구조적인 저차원 매니폴드를 형성한다고 했다. 경사 하강법으로 모델 곡선을 데이터에 맞춰가다 보면 곡선은 데이터가 놓인 매니폴드의 모양을 대략적으로 근사한다.

                              실제로 그림을 보면 어느 순간 곡선이 데이터의 진짜 매니폴드 모양과 거의 겹치는 최적적합 상태에 도달한다.

                              근데 여기서 멈추지 않고 계속 훈련하면 곡선은 매니폴드를 지나쳐서 개별 점 하나하나에 억지로 달라붙기 시작한다. 이것이 과대적합이며 모델이 훈련 데이터를 그저 암기하고 있는 단계가 된다.

                              최적 지점에 학습을 멈춰서 매니폴드를 잘 근사한 곡선 위에서의 보간이 일반화이다.

                              #

                              4. 일반화 #

                              딥러닝의 일반화는 데이터 매니폴드를 잘 근사하는것이다.

                              좋은 모델을 만들기 위해서는 매니폴드를 촘촘하게 덮을수있도록 좋고 많은 데이터로 훈련해야 한다. 특히 클래스 사이 결정 경계에서의 촘촘한 샘플링이 중요하다.

                              좋은 데이터를 만드는데 데이터 큐레이션과 특성 공학이 필요하다.

                              또한 모델이 저장할 수 있는 정보량을 제한하거나, 곡선이 지나치게 구불구불해지지 못하게 매끄러움에 제약을 거는 등의 장치를 함으로써 모델이 일반화에 유용한 패널에 집중할수있게 하는 방법도 있다. (규제)

                              정리하면, 세상의 데이터가 매끄러운 매니폴드 위에 놓여 있고(매니폴드 가설), 딥러닝 모델은 매끄러운 곡선이라 그 매니폴드를 잘 근사할 수 있으며(딥러닝이 작동하는 이유), 일단 근사하고 나면 그 위에서 아는 점들 사이를 채워 새 입력을 이해한다(보간이 곧 일반화).

                              다만 이 보간은 아는 것의 이웃까지만 닿는 지역 일반화일 뿐, 사람의 궁극 일반화와는 아직 거리가 멀다.
