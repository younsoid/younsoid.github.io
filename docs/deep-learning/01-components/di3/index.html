                            역전파 알고리즘 #

                            #2026-07-30

                            심층 신경망 모델은 층을 쌓아서 만든것이고 층이 데이터의 표현을 유용하게 변환한다고 했다.

                            각 층의 데이터 변환은 그 층의 가중치를 파라미터로 갖는 함수로 나타내진다. 고로 학습이란 즉 학습의 목표는 입력을 타깃에 매핑하기위해 신경망의 모든층의 가중치값을 찾는것이라고 할수있다.

                            정확한 파라미터값을 찾기위해 파라미터를 조정하려면 출력이 기대와 얼마나 다른지 측정해야한다. 손실함수가 예측과 타깃의 차이를 점수로 계산한다.

                            현재 샘플의 손실점수가 감소되는 방향으로 가중치 값을 수정하는것이 딥러닝의 핵심 알고리즘인 역전파 알고리즘이다.

                            로직은 이렇다. 처음에는 랜덤한 가중치로 랜덤하게 변환을 수행한다. 당연히 출력과 기대가 다르고 손실점수가 높다. 네트워크가 샘플들을 처리하면서 가중치가 제대로 조정되고 손실점수도 감소한다.

                            이러한 트레이닝 루프를 반복(일반적으로 수천개 샘플에서 수십번 반복)해서 만들어진 최소한의 손실을 만드는 네트워크가, 타깃에 가장 가까운 출력을 만드는 모델이 된다.
