                    사전 훈련 모델의 미세 조정 #

                    #2026-10-19

                    1. 미세 조정 #

                    앞서 사전 훈련된 모델은 2가지 방법으로 사용할수있다고 했다. 첫번째는 ‘이미지’에 대한 이해가 있는 그 모델을 사용해서 내 이미지들의 특성을 추출하는것이이었다.

                    두번째는 그 모델을 내 이미지에 맞게 미세조정하는것이다. 미세 조정은 특성 추출에 사용했던 동결 모델의 상위층 몇개를 동결 해제하고, 모델에 새로 추가한 층(밀집 분류기)과 함께 훈련하는 것이다.

                    conv_base = keras.applications.vgg16.VGG16(
  weights="imagenet",
  include_top=False)

conv_base.trainable = False

                    기존에는 conv_base의 합성곱 층을 동결해서 합성곱 층의 가중치가 수정되지 않고 밀집 분류기(Dense 층)만 학습되게 했다. 미세 조정에서는 여기서 다음 단계로, 일부 층의 동결을 해제해서 한번더 훈련하는것이다.

                    순서를 나열하면 이렇다.

                    1. “연속 합성곱과 풀링 층 -> 밀집 연결 분류기” 구성을 만든다. (연속 합성곱과 풀링층은 사전에 훈련된것, 밀집 연결 분류기는 랜덤하게 초기화됨)
                    2. 연속 합성곱과 풀링층을 동결한다.
                    3. 밀집 연결 분류기를 훈련한다.
                    4. 연속 합성곱과 풀링층에서 일부 층의 동결을 해제한다. (이때 배치 정규화 층은 해제하면 안됨)
                    5. 동결을 해제한 층과 분류기를 다시 같이 훈련한다.

                    2. 미세 조정할 모델 세팅 #

                    conv_base = keras.applications.vgg16.VGG16(
  weights="imagenet",
  include_top=False)

conv_base.trainable = False

                    먼저 기존과 똑같이 합성곱 층을 동결한 conv_base를 만든 다음에

                    data_augmentation = keras.Sequential(
  [
    layers.RandomFlip("horizontal"),
    layers.RandomRotation(0.1),
    layers.RandomZoom(0.2),
  ]
)

inputs = keras.Input(shape=(180, 180, 3))
x = data_augmentation(inputs)
x = keras.applications.vgg16.preprocess_input(x)
x = conv_base(x)
x = layers.Flatten()(x)
x = layers.Dense(256)(x)
x = layers.Dropout(0.5)(x)

outputs = layers.Dense(1, activation="sigmoid")(x)
model = keras.Model(inputs, outputs)
model.compile(loss="binary_crossentropy",
              optimizer="rmsprop",
              metrics=["accuracy"])

                    “동결된 합성곱 층 - 밀집 분류기"로 구성된 새로운 모델 model을 만들고

                    callbacks = [
  keras.callbacks.ModelCheckpoint(

]
history = model.fit(

                    3. 미세 조정 실습 #

                    conv_base.trainable = True
for layer in conv_base.layers[:-4]:
  layer.trainable = False

                    마지막에서 4번째 층까지 동결하고 1~3번째 층은 풀어놓는다.

                    model = keras.Model(inputs, outputs)
model.compile(loss="binary_crossentropy",
              optimizer=keras.optimizers.RMSprop(learning_rate=1e-5), # 분류기 학습에서는 optimizer="rmsprop"
              metrics=["accuracy"])

callbacks = [
  keras.callbacks.ModelCheckpoint(
      filepath="fine_tuning.h5",
      save_best_only=True,
      monitor="val_loss")
]
history = model.fit(
  train_dataset,
  epochs=30, 
  validation_data=validation_dataset, 
  callbacks=callbacks)

                    미세 조정에는 RMSProp 옵티마이저를 쓰되 학습률을 낮춘다. 3개 층에서 학습된 표현을 조금씩만 수정하기 위해서이다.

                    테스트에서 모델을 평가해보면 98.5%가 나온다고 한다. 훈련 데이터의 약 10%만 사용해도 높은 성능이 나오는 것이다.
