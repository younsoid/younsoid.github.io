                    컨브넷의 기본구조 #

                    #2026-10-09

                    1. 기본 구조 #

                    input (, 28, 28, 1)
conv2d -> (, 26, 26, 32)
max pooling 2d -> (, 13, 13, 32)
conv2d -> (, 11, 11, 64)
max pooling 2d -> (, 5, 5, 64)
conv2d -> (, 3, 3, 128)
flatten -> (, 1152)
dense -> (, 10)

                    기본 컨브넷 모델의 층 구성과 output 크기는 위와 같다. conv2d와 max pooling 2d의 출력은 (높이, 너비, channels) 크기의 랭크-3 텐서이다.

                    마지막 conv2d 층의 출력은 128개 채널을 가진 3x3 특성맵이다. (3, 3, 128)

                    앞서 컨브넷 모델은 특성 추출 -> 밀집 분류기라고 했었는데 밀집 분류기는 Dense층을 쌓은 것이다. 이 분류기는 1D를 input으로 받기때문에 특성맵을 1D 텐서로 flatten하고 분류기에 넣는다.

                    완전 연결 모델                          파라미터
input       -> (, 28, 28, 1)
flatten     -> (, 784)                 0
dense(512)  -> (, 512)                 784 × 512 + 512 = 401,920
dense(10)   -> (, 10)                  512 × 10 + 10   =   5,130
                                       합계              407,050

                    위는 28×28 이미지 input -> 784개 숫자로 flatten -> Dense(512) -> Dense(10)을 쌓는 완전 연결 모델이다.

                    완전 연결 모델은 특성 추출기가 따로 없다. 굳이 따지만 첫번째 Dense 층이 분류, 특성 추출을 둘다 한다.

                    컨브넷 모델                             파라미터
input        -> (, 28, 28, 1)
conv2d       -> (, 26, 26, 32)         3×3×1×32 + 32    =    320
max pooling  -> (, 13, 13, 32)         0
conv2d       -> (, 11, 11, 64)         3×3×32×64 + 64   = 18,496
max pooling  -> (, 5, 5, 64)           0
conv2d       -> (, 3, 3, 128)          3×3×64×128 + 128 = 73,856
flatten      -> (, 1152)               0
dense(10)    -> (, 10)                 1152 × 10 + 10   = 11,530
                                       합계              104,202

                    컨브넷은 특성 추출을 Dense 대신 합성곱으로 바꾼 것이다.

                    여기서 오는 차이는, dense 층은 입력 특성 공간에 있는 전역 패턴을 학습하지만 합성곱 층은 지역 패턴을 학습한다. 이미지일 경우 2x2 window만 보고 패턴을 찾는다.

                    2. 컨브넷의 특성 #

                    이러한 구조 차이에서 오는 특성 차이는 2가지가 있다.

                    첫번째는 학습된 패턴이 평행이동 불변성을 갖는다는 것이다. (translation invariant) 컨브넷이 이미지의 오른쪽 아래 모서리에서 어떤 패턴을 학습했다면 다른곳인 왼쪽 위 모서리에서도 이 패턴을 인식할 수 있다.

                    완전 연결 네트워크였으면 새로운 위치에 나타난것은 그것만 보고 새로운 (그것만의) 패턴으로 학습해야하는데 근본적으로 우리가 보는 세상은 평행 이동으로 인해 다르게 인식되지 않기 때문에 컨브넷은 이미지를 효율적으로 처리(패턴 인식)한다고 볼수있다.

                    두번째는 패턴의 공간적 계층 구조를 학습할 수 있다는 것이다. 첫번째 합성곱 층은 에지 같은 작은 지역 패턴을 학습하고, 두번째 합성곱 층은 첫번째 층의 특성으로 구성된 더 큰 패턴을 학습한다.

                    근본적으로 우리가 보는 세상은 공간적 계층 구조를 가지고 있기 때문에 컨브넷의 특성은 매우 복잡하고 추상적인 시각적 개념을 효과적으로 학습할수있다.
