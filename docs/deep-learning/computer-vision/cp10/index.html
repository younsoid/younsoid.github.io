                    합성곱 연산 #

                    #2026-10-09

                    컨브넷의 특성인 합성곱 연산은 입력이 특성맵이라는 랭크-3 텐서이다.

                    이 텐서는 2개의 공간축(높이, 너비)와 1개의 깊이 축(채널)으로 구성된다. 채널 개념은, RGB 이미지는 3개의 컬러 채널을 가져서 채널 3이고 MNIST 이미지처럼 흑백 이미지면 채널 1이 된다.

                    합성곱 연산은 입력 특성 맵에서 작은 패치들을 추출하고 모든 패치들에 같은 변환을 적용해서 출력 특성맵을 만든다. 출력 특성맵도 높이, 너비, 채널을 가진 랭크-3 텐서인데 출력 텐서의 깊이는 층의 매개변수로 결정되기 때문에 상황에 따라 다르다.

                    이 출력맵의 채널은 RGB 색깔이 아닌 “입력 데이터의 어떤 특성을 인코딩한 값"이 된다. (필터) 예를 들어 하나의 필터가 ‘입력에 얼굴이 있는지’를 인코딩할 수 있다.

                    합성곱 층이 (28, 28, 1) 특성맵을 받으면 (26, 26, 32) 특성맵을 출력할 수 있다. 이는 입력에 대해 32개의 필터를 적용했다는 것이다. 입력을 32가지 측면에서 바라본것이다.

                    32개 출력 채널 각각이 갖는 26x26 크기 배열값은 입력에 대한 각 필터의 응답맵이라고 한다. 입력의 각 위치에서 필터 패턴에 대한 응답맵이다.
