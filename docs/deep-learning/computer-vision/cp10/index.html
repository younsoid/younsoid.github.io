                    합성곱 연산 #

                    #2026-10-11

                    1. 합성곱 연산 #

                    컨브넷의 특성인 합성곱 연산은 입력이 특성맵이라는 랭크-3 텐서이다.

                    이 텐서는 2개의 공간축(높이, 너비)와 1개의 깊이 축(채널)으로 구성된다. 채널 개념은, RGB 이미지는 3개의 컬러 채널을 가져서 채널 3이고 MNIST 이미지처럼 흑백 이미지면 채널 1이 된다.

                    합성곱 연산은 입력 특성 맵에서 작은 패치들을 추출하고 모든 패치들에 같은 변환을 적용해서 출력 특성맵을 만든다. 출력 특성맵도 높이, 너비, 채널을 가진 랭크-3 텐서인데 출력 텐서의 깊이는 층의 매개변수로 결정되기 때문에 상황에 따라 다르다.

                    출력맵의 채널은 RGB 색깔이 아닌 “입력 데이터의 어떤 특성을 인코딩한 값"이 된다. (필터) 예를 들어 하나의 필터가 ‘입력에 얼굴이 있는지’를 인코딩할 수 있다.

                    합성곱 층이 (28, 28, 1) 특성맵을 받으면 (26, 26, 32) 특성맵을 출력할 수 있다. 32개 출력 채널 각각이 갖는 26x26 크기 배열값은 입력에 대한 응답맵이라고 한다. 입력의 각 위치에서 필터 패턴에 대한 응답맵이다.

                    (28, 28, 1) 특성맵을 받으면 (26, 26, 32) 특성맵을 출력한다고 했는데, 이는 입력에 대해 32개의 필터를 적용했다는 것이다. 입력을 32가지 측면에서 바라본것이다.

                    2. 특성맵 #

                    특성맵은 (공간-높이, 공간-너비, 깊이-채널) 구성이다.

                    깊이 축의 각 차원은 하나의 특성 또는 필터이다. 각 필터의 출력 output[:, :, n]은 랭크-2 텐서로 입력에 대한 이 필터의 응답인 2D 맵이다.

                    3. 파라미터 #

                    합성곱은 2개 파라미터로 정의된다.

                    첫번째는 입력으로부터 뽑아낼 패치의 크기인데 보통 3x3, 5x5를 사용한다.

                    두번째는 특성맵의 출력 깊이인데 합성곱으로 필터 몇개를 계산할것인지, 몇개의 방향으로 입력을 바라볼것인지이다. 숫자는 보통 깊이 32로 시작해서 깊이 128로 끝나는 식이다.

                    4. 작동 #

                    합성곱은 3D 입력 특성맵 위를 3x3 또는 5x5 크기의 윈도우가 슬라이딩하면서 모든 위치에서 3D 특성 패치 (window_height, window_width, input_depth)를 추출하는 식으로 작동한다.

                    이 3D 패치에 학습된 가중치 행렬(합성곱 커널)을 텐서 곱셈하면 (output_depth, ) 크기의 1D 벡터로 변환된다. 합성곱 커널은 모든 패치에 대해 재사용된다.

                    변환된 모든 벡터는 합쳐서 (height, width, output_depth) 크기의 3D 출력 특성맵이 된다.

                    출력 특성맵의 공간상 위치는 입력 특성맵의 같은 위치에 대응되지만, 2가지 이유로 출력 높이와 너비가 입력 높이와 너비 (정확히는 입력 높이와 너비 - 패치의 크기)와 다를 수 있다.

                    첫번째는 경계 문제로, 입력 특성맵에 패딩을 추가해서 대응할 수 있다. 두번째는 스트라이드의 사용 여부에 따라 다르다.
