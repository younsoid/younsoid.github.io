                    합성곱에서 깊이 #

                    #2026-10-11

                    입력 값의 깊이, 입력 특성맵의 깊이, 출력 특성맵의 깊이가 각각 의미하는것은?

                    이미지 (28, 28, 1)          ← 입력 값의 깊이 1 (흑백)
  ↓
conv2d(32)                  입력 깊이 1  → 필터 모양 3×3×1,  32개 → 출력 깊이 32
  ↓ (26, 26, 32)
max pooling                 깊이는 그대로 32
  ↓ (13, 13, 32)
conv2d(64)                  입력 깊이 32 → 필터 모양 3×3×32, 64개 → 출력 깊이 64
  ↓ (11, 11, 64)
max pooling                 깊이는 그대로 64
  ↓ (5, 5, 64)
conv2d(128)                 입력 깊이 64 → 필터 모양 3×3×64, 128개 → 출력 깊이 128
  ↓ (3, 3, 128)

                    입력 값의 깊이는 모델에 맨 처음 들어가는 이미지 자체의 채널 수이다. 컬러 사진이면 빨강, 초록, 파랑 밝기 세 장이 겹쳐 있어서 3이고, MNIST 같은 흑백 이미지면 밝기 한 장이어서 1이다. 이 단계의 채널은 “색"이라는 물리적 의미이다.

                    입력 특성 맵의 깊이는 지금 이 합성곱 층에게 들어오는 텐서의 채널 수이다. 첫 번째 층이라면 이미지가 바로 들어오니 입력 값의 깊이와 같다. 두 번째 층부터는 앞 층의 출력이 들어오므로 앞 층의 출력 깊이가 이 층의 입력 깊이가 된다.

                    이때부터 채널은 색이 아니라 앞 층의 필터들이 찾아낸 특징들이다.

                    출력 특성 맵의 깊이는 이 층에 있는 필터의 개수이다. Conv2D(64, 3)의 64가 이 값인데 입력을 몇 가지 관점으로 볼 것인가에 대한 값이다.

                    이미지 (28, 28, 1)          ← 입력 값의 깊이 1 (흑백)
  ↓
conv2d(d1)                  입력 깊이 1  → 필터 모양 3×3×1,  d1개 → 출력 깊이 d1
  ↓ (26, 26, d1)
max pooling                 깊이는 그대로 d1
  ↓ (13, 13, d1)
conv2d(64)                  입력 깊이 d1 → 필터 모양 3×3×d1, d2개 → 출력 깊이 d2
  ↓ (11, 11, d2)
max pooling                 깊이는 그대로 d2
  ↓ (5, 5, d2)
conv2d(128)                 입력 깊이 d2 → 필터 모양 3×3×d2, d3개 → 출력 깊이 d3
  ↓ (3, 3, d3)

                    추가로, 필터는 입력의 모든 채널을 한꺼번에 덮어야 하므로 두께가 입력 깊이와 같아야 한다. 입력 깊이가 32면 3×3 필터는 실제로 3×3×32개의 숫자로 이루어지고, 뽑아내는 패치도 (3, 3, 32)이다.
