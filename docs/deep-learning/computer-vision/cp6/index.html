                    좋은 모델 아키텍처 #

                    #2026-10-07

                    모델의 아키텍처는 모델을 만드는데 사용한 일련의 선택들이다. 사용할 층, 층의 옵션, 층 연결 방법 등의 선택이 모델의 가설 공간을 정의한다.

                    가설 공간은 경사 하강법이 검색할수있는 가능한 함수의 공간이다. 좋은 가설공간은 풀고자 하는 문제와 솔루션에 대한 사전 지식을 담고있다. (인코딩한다)

                    예를 들어 합성곱 층을 사용한다는 것은 입력 이미지에 있는 패턴이 이동 불변성이 있음을 미리 알고있다는 뜻이다. 데이터에서 학습을 효율적으로 하려면 이처럼 찾고 있는 것에 대한 가정을 해야 한다.

                    적절하지 않은 아키텍처를 선택하면 데이터가 많더라도 모델이 특정 선 이상으로 성능이 올라가지 않는다. 좋은 모델 아키텍처는 1) 학습을 가속하고 2) 모델이 훈련 데이터를 효율적으로 사용하게 만들어서 대규모 데이터셋이 아니더라도 핵심을 파악하고 성능이 올라가게 된다.

                    좋은 모델 아키텍처는 탐색 공간의 크기를 줄이거나 탐색 공간의 좋은 위치에 쉽게 수렴할 수 있는 설계다. 경사 하강법이 해결할 문제를 간단하게 만드는 설계이다.

                    숙련된 머신러닝 엔지니어는 첫번째 시도에서 고성능 모델을 직관적으로 조합할 수 있다. 여기서 키워드는 ‘직관적’인데, 어떤 방법이 좋고 안좋고는 명확하게 설명하기 어려우며 다양한 실전 경험을 통해 얻은 능력인 패턴 매칭으로 모델을 설계하는 것이다.
